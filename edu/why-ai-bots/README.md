# Why AI Bots — 교육 패키지 (AI 대항해 시대)

Notion 대본 32클립을 **슬라이드(장표) 레이아웃** HTML + 나레이션으로 묶은 교육 자료입니다.

- **형식**: 설명 30분 · 질의 없음
- **날짜**: 2026-10-01 education material
- **경로**: `edu/why-ai-bots/`

## 최소 구성 (기록 범위)
- `why-ai-bots.html` — 오프닝 + 29장(9장에 OpenClaw 사례 1화면 추가, 총 30화면) + 엔딩
- `narration.json` — 32클립 나레이션 (`lines[]` 유지)
- `slide-visible-copy.md` — 화면에 보이는 층 카피 (SCENES에서 자동 생성)
- `SOURCES.md` — 신규 배경·연결 표준·리스크 이름 장의 1차 출처와 미사용 항목

실행에 필요한 `assets/bg`(배경 1종)와 `assets/photos`(CC 사진 9장, 크레딧은 `assets/photos/CREDITS.md`)를 함께 둡니다. 로고·인물 초상·제품 UI 스크린샷·미PASS 수치는 넣지 않습니다.

## 장 구성
1~4장 표지·질문·용어·시작점 → 5~8장 배경 → 9장 병행 세 경로 → 10~13장 열광 네 축 → 14~16장 Grok Bot → 17~19장 Muse → 20~21장 Dots → 22장 비교 → 23장 공통 뼈대 → 24장 연결 표준 → 25장 리스크 → 26장 확인된 사건 → 27장 리스크 이름(OWASP ASI 대조, 해석 표기) → 28장 전망 → 29장 그래서 우리는.

## 서사 잠금 (기획·작가)
1. **병행 세 경로** — 자가호스팅 · 에이전트 소셜 · 클라우드 (단일 발전사/필연 순서 금지). 9장 다이어그램.
2. **22장 4행 비교표** — 실행 환경 / 자동 통제 / 사람 승인 / 운영 주의 (+ Network Controls). Auto Review ≠ Sentinel.
3. **설정값 세 개 (29장)** — 네트워크 정책 · 로컬 Never · 오프보딩.
