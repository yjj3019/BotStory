# 내용 정리와 출처 확인 범위

기존 29장·30화면의 서사를 유지해 오프닝, 본문 30클립, 엔딩으로 정리했습니다. 낭독문은 해요체를 유지하고, 영문 제품명과 약어는 한글 읽기로 통일했습니다. 새 음성은 만들지 않았습니다.

## 주요 정정

- 오프닝의 고정 시간 약속과 모든 가격이 공식 원문으로 확인됐다는 표현을 삭제했습니다. 표지에서는 10월 1일 교육본과 10월 5일 원고 개정을 구분했습니다.
- 챗봇·에이전트는 학습용 구분이며 이름만으로 권한이나 성공을 보장하지 않는다고 설명했습니다. 기억과 실행 환경의 효과도 보장으로 단정하지 않습니다.
- 자가호스팅이 자동 격리를 뜻하지 않으며 OpenClaw에도 실행 승인 기능이 있음을 반영했습니다. [OpenClaw 샌드박스](https://docs.openclaw.ai/gateway/sandboxing), [실행 승인](https://docs.openclaw.ai/tools/exec-approvals)
- Muse의 Sentinel이 커넥터·네트워크 권한과 필요한 사람 승인을 처리한다는 공식 설계에 맞춰, 사람 승인을 Sentinel과 완전히 별개로 설명하던 문장을 정정했습니다. [Meta 안전 설계](https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse)
- Dots의 개인 Pro 제공 지역과 Business Premium 제공 지역을 구분했습니다. 정확한 연령 수치를 이번에 직접 확인하지 못해 제외했고, 비밀번호 변경은 사용자가 직접 처리하는 단계임을 유지했습니다. [시작 안내](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot), [통제 안내](https://learn.chatgpt.com/docs/dots/controls)
- Moltbook 사고는 공개 데이터베이스 키 자체와 RLS 접근 제어 설정 누락을 구분했습니다. 원고에서는 약어를 “알엘에스”로 읽습니다. [Wiz 원조사](https://www.wiz.io/blog/exposed-moltbook-database-reveals-millions-of-api-keys)
- 로컬 실행 자체와 의도·승인 범위를 벗어난 코드 실행을 구분했습니다. OWASP 항목과의 연결은 자료의 해석이며 정상 로컬 실행을 사고로 단정하지 않습니다.
- 현재 출시 제품과 미공개 후속 모델에 관한 보도를 구분했습니다. 후속 모델 출시 취소가 현재 제품의 실패를 입증하는 것처럼 연결하지 않습니다.

## 남는 확인 범위

- Muse 요금은 2026년 9월 안내 요약의 재인용입니다. 이번에 공식 요금 원문을 다시 확인하지 못했다는 말을 원고 안에도 남겼습니다. 현재 금액·지역·계정 조건은 이용 전에 확인해야 합니다.
- Muse Confidential VM은 2026년 9월 발표 당시의 연내 제공 계획으로 설명합니다. 원고는 출시 완료를 확인했다고 주장하지 않습니다.
- OpenClaw의 초기 공개 이력과 과거 GitHub 스타 수는 기존 자료가 인용한 이력·당시 보도에 근거한 설명입니다. 스타 수를 실제 사용자 수나 업무 성과로 해석하지 않습니다.
- 바이첸바움의 1976년 저서에 관한 경고는 전해지는 취지를 요약한 문장입니다. 원문 직접 인용으로 제시하지 않습니다.
- 기업 소개·공식 설계 문서를 대조했지만 각 제품을 직접 실행해 성능을 측정한 검증은 아닙니다. 전체 출처 기록은 저장소의 `edu/why-ai-bots/SOURCES.md`에 있습니다.

원고의 학습용 예시는 특정 제품에서 실제 실행한 결과가 아닙니다. 최종 음성의 발음, 자연스러움, 누락·반복과 장표 동기는 사용자가 음성을 렌더링한 뒤 확인해야 합니다.
