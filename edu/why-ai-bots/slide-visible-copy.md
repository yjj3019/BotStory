# 장표 카피 (밀도 리디자인 · 보이는 층)
나레이션 lines는 유지. 아래는 화면에 보일 층만.
출처: 사실 원장 · 교육본 PASS · 확인일 2026-09-20
가드: 새 수치·요금 단정·Enterprise 웨이팅·Hermes 일자·「진행 경로」금지 · 「병행 세 경로」유지 · Auto Review≠Sentinel

## 01. 표지
- **메시지** AI Bot 시대, 왜 열광하는가를 위임·지속·실행 환경으로 본다
- **카드/불릿**
  - 시작점 → 병행 세 경로 → Grok Bot·Muse 증거
  - 제품 카탈로그가 아니라 “왜”가 본체
  - 설명 30분 · 질의 없음
  - 과장·미확인 수치 배제

## 02. 오늘의 질문
- **메시지** 챗봇은 대답했고, 봇은 일을 맡기기 시작했다
- **카드/불릿**
  - 시작점: 미완의 위임
  - 병행 세 경로: 자가호스팅 · 에이전트 소셜 · 클라우드
  - 현재: 위임·지속·실행환경·접근성(+과열) ↔ 격리·승인
  - 비교는 증거 뒤에

## 03. 이름만 같다고 같은 도구가 아니다
- **메시지** 같은 “봇”이라도 실행·지속·권한이 다르다
- **카드/불릿**
  - **다이어그램 주비주얼** `diagrams/03-terminology-path.png`
  - 챗봇 ≠ 위임형 agent
  - 용어를 가른 뒤 시작점으로
- **표** (간단) 실행 / 지속성 / 권한 — 교육본 03 표 셀 그대로

## 04. 시작점 — 미완의 위임
- **메시지** 답만 주고 일이 끝나지 않았다
- **카드/불릿**
  - 조사·초안은 됨 · 툴 반영·마무리는 사람 몫
  - 세션이 바뀌면 맥락이 끊김
  - “도와준다” ≠ “맡긴다”
  - 결핍: 실행 · 권한 · 지속성 패키지

## 05. 병행 세 경로
- **메시지** BOT 수요 반응이 하나의 발전사가 아니라 세 경로로 병행됐다
- **카드/불릿**
  - **다이어그램 주비주얼** `diagrams/05-progress-path.png` · alt/캡션 「병행 세 경로」
  - ① 자가호스팅 (OpenClaw · Hermes) — 격리=내 서버 · 승인은 직접 구현
  - ② 에이전트 소셜 (Moltbook)
  - ③ 클라우드 제품 (Grok Bot · Muse)
- **표** 경로|사례|한 줄|비고 — Hermes 일자 단정 금지 · OpenClaw 기원 선언 금지

## 06. 열광① 위임
- **메시지** 답이 아니라 결과를 맡긴다
- **카드/불릿**
  - 문장 생성이 아니라 일 위임
  - 저위험부터 · 사람 승인 게이트
  - 과도 위임이 곧 리스크
  - (카드 그리드 1/4)

## 07. 열광② 지속성
- **메시지** 세션이 끊겨도 맥락이 남는다
- **카드/불릿**
  - 메모리·루틴·파일
  - 어제 일을 오늘 다시 설명하지 않음
  - 지속 = 편의이자 잔존 자격증명 주의
  - (카드 그리드 2/4)

## 08. 열광③ 실행 기반
- **메시지** 위임의 실행 기반이 제품이 되었다
- **카드/불릿**
  - **다이어그램 주비주얼** `diagrams/08-runtime-computer-vs-secure-vm.png`
  - Grok: 사용자당 cloud computer (봇마다 전용 PC는 오해)
  - Muse: 개인별 Secure VM
  - 로컬 실행은 클라우드 Auto Review와 별도 · Never 권고

## 09. 열광④ 접근성(+과열)
- **메시지** 가까워질수록 기대와 과열이 같이 커진다
- **카드/불릿**
  - 채널·앱·메신저로 진입 장벽↓
  - 과열 ≠ 근거
  - 스타·가입 수 말하지 않음
  - (카드 그리드 4/4)

## 10. 증거 A — Grok Bot 출시·제품
- **메시지** Grok Bot은 위임을 클라우드 computer 위에 올린 현재형이다
- **카드/불릿**
  - 2026-08-11 beta · SpaceXAI / Cursor 클라우드
  - 사용자 단위 computer · 동일 사용자 Bot 간 파일·브라우저·로그인 공유
  - 삭제 ≠ 자격증명 회수
  - Enterprise: 2026-09-03 **출시** (웨이팅 아님) · access/network/audit

## 11. Grok Bot — 통제·로컬
- **메시지** 격리는 computer만이 아니다 · 로컬·네트워크를 같이 본다
- **카드/불릿**
  - Auto Review: 모델 기반 위험 평가 · 최소권한·명시 경계 **대체 금지**
  - Network Controls: Enterprise 전용 · 없으면 allow-all
  - 로컬 실행: 데스크톱 앱→실제 PC · 기본 Never 권고
  - 사람 승인: 민감·로그인·2FA·결제

## 12. Grok Bot — 인용·가드
- **메시지** 인용은 전망으로 읽고 SLA로 읽지 않는다
- **카드/불릿**
  - Roman Ugarte 인용 카드(초상 없음)
  - Galaxy: 2026-09-15~17 **일정만**
  - 요금: 번들·플랜+URL · 단독 정가 단정 금지
  - docs: computer-and-apps · security-faq 병기

## 13. 증거 B — Muse 출시·요금
- **메시지** Muse는 개인 agent를 Secure VM 위에 둔 미국 롤아웃이다
- **카드/불릿**
  - 2026-09-08 발표 · iOS/Android/WhatsApp 등
  - 요금: 무료 한도 + Power/Maximum — **Help URL만** (수치 단정 최소화)
  - Muse Spark · Link(Stripe) 1회용 카드(승인 서사)
  - 사내 배포 방식은 발표문에 없음

## 14. Muse — Secure VM·Sentinel
- **메시지** Sentinel은 승인 UI가 아니라 egress·커널 중개 계층이다
- **카드/불릿**
  - Secure VM · Sentinel(커넥터·네트워크 egress)
  - surrogate 토큰 · 비밀값은 경계에서 주입
  - Confidential VM: later this year · **미출시** · 신뢰 간극을 메우려는 예정
  - `[보도]`는 태그로만 · 본문 단정 금지

## 15. Muse 전망 — 발언/사실/해석
- **메시지** 기업 발언·사실·해석을 표로 가른다
- **표**
  | 칸 | 내용 | 말하는 법 |
  | 기업 발언 | personal superintelligence 등 장기 방향 | 전망 라벨 |
  | 사실 | 미국 롤아웃 · Secure VM · Sentinel · Confidential VM 미출시 · Help 요금 URL | 원장만 |
  | 해석 | 소셜·글라스 결합 · 사내 배포 | 가능성만 · 확인 불가 |

## 16. 비교 — 등가 금지
- **메시지** 실행 환경 / 자동 통제 / 사람 승인 / 운영 주의로만 겹친다
- **카드/불릿**
  - **다이어그램 주비주얼** `diagrams/16-isolation-auto-review-sentinel.png`
  - Auto Review(모델) ≠ Sentinel(egress/커널)
- **표**
  | | Grok Bot | Muse |
  | 실행 환경 | 사용자당 cloud computer | 개인별 Secure VM |
  | 자동 통제 | Auto Review(모델 기반) | Sentinel(egress/커널 중개) |
  | 사람 승인 | 민감·로그인·2FA·결제 | 메일·구매 등 |
  | 운영 주의 | Bot 간 공유·오프보딩 / Network Controls=Enterprise·없으면 allow-all / 로컬 Never | Confidential VM 미출시(신뢰 간극) |

## 17. 공통 뼈대 다섯
- **메시지** 제품 이름 전에 다섯 뼈대를 본다
- **카드/불릿**
  - **다이어그램 주비주얼** `diagrams/17-common-skeleton-five.png`
  - 위임 · 지속 · 실행 기반 · 격리 단위 · 승인
  - 자가호스팅 선행: 격리=내 서버 · 승인은 사용자가 구현
  - 클라우드 제품은 같은 뼈대의 다른 구현

## 18. 리스크와 완화
- **메시지** 위임이 커질수록 리스크도 커진다 · 완화 한 줄을 붙인다
- **표**
  | 리스크 | 완화 |
  | 자격증명·잔존 로그인 | 최소 권한 · 삭제≠회수 · 오프보딩 순서 |
  | 오작동·과도 위임 | 저위험부터 · 사람 승인 · Auto Review 대체 금지 |
  | 프라이버시·접근 간극 | 연결 범위 · Confidential VM 미출시(간극) · `[보도]` 태그 |
  | 네트워크·비용 | Network Controls=Enterprise · 요금은 Help URL · 한도 모니터링 |
  | 로컬 실행·책임 | Auto Review와 별도 · Never 권고 · 감사 로그 |

## 19. 전망 세 갈래
- **메시지** 예측이 아니라 관찰 포인트 세 갈래다
- **표**
  | 갈래 | 관찰 신호 | 비고 |
  | 개인 비서 대중화 | 지원 국가·채널 · Help 요금·한도 | 미국 롤아웃과 분리 |
  | 기업 디지털 인력 | Enterprise 감사·Network Controls · 조직 Enable | Enterprise 9/3 출시 |
  | 규제·신뢰 속도 조절 | 법제 · Confidential VM 출시 여부 | 전망 라벨 |

## 20. 설정값 세 개
- **메시지** 도입 선언보다 설정값 세 개를 익힌다
- **카드/불릿** (3카드)
  - **네트워크 정책** — Enterprise 전용 · 없으면 전체 허용이 기본
  - **로컬 실행 정책** — Never 권고
  - **오프보딩** — 루틴 정지 → 웹 로그아웃 → 커넥터 해지 → 작업 파일 삭제 (봇 삭제≠자격증명 회수)
