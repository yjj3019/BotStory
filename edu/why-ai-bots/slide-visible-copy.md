## 13장 · Grok 개요
- **메시지** Grok Bot은 위임을 클라우드 computer 위에 올린 현재형이다
- 2026-08-11 — beta 공개
- 2026-08-26 — 접근 플랜 확대
- 2026-09-03 — Enterprise — 출시 — 2주 무료 체험 · 조직 초대

## 14장 · Grok 구조
- **메시지** 격리는 computer만이 아니다 · 로컬·네트워크를 같이 본다
- 사용자 단위 cloud computer 위의 역할 Bot 명단 — 봇을 지워도 파일·로그인은 남을 수 있음
  - 조사
  - 검증
  - 작성
- 통제는 한 겹이 아니다
- Auto Review
  - 모델 기반 위험 평가
  - 최소 권한·명시 경계를 대체하지 않음
  - 메모리·대부분 설정은 검토 대상 아님
- 사람 승인
  - 민감 행동 · 로그인 · 2FA · 결제
- Network Controls
  - Enterprise 전용 · 정책 없으면 전체 허용(allow-all)
- 로컬 실행
  - 데스크톱 앱 → 실제 PC
  - Auto Review와 별도 통제
  - 기본 Ask · Never 권고
